# Design reference

`screens/` holds screenshots of the approved product prototype. They are the visual source of truth for web screens:
tokens, components and layout are specified in [`../features/003-ui-design-system.md`](../features/003-ui-design-system.md).

Screens that exist today are restyled in feature 003. The others (plots, ownership, payments, map, member balance and
invoice, operator console, mobile) show the target style for the features that build them; their content and rules come
from each feature's own spec, not from the screenshot. Data in the screenshots is fictional.
