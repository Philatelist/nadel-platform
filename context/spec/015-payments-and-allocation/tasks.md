# Tasks: Payments, cash desk and allocation (015)

Rules for every slice: contract first (`api/openapi.yaml`, then `make gen`); schema only through the new Flyway
migration V27 (later slices add V28+ only if needed, never edit an applied one); every text through the i18n catalogs
(uk default, both catalogs); only the server calculates money (the web shows server strings, never sums); ledger rows
are append-only; no personal data in logs; no new dependency; no edits to generated code; Conventional Commits, no AI
attribution in commits. Verify tasks run only the slice's own narrow tests (CLAUDE.md verification levels); the full
`make check` and `make e2e` run once in Phase 4. Every Verify task stops anything it started and deletes its own
temporary files. References "TC x.y" are sections of `technical-considerations.md`; "FS x.y" of `functional-spec.md`.
