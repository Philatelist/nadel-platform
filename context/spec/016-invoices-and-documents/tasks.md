# Tasks: Invoices with the NBU QR code, debt certificates and cash receipts (016)

Rules for every slice: contract first (`api/openapi.yaml`, then `make gen`); schema only through the new Flyway
migration V28 (written in Slice 2 with every 016 table; a later slice adds V29+ only if needed, never edits an applied
one); every screen text through the i18n catalogs (uk default, both catalogs); document texts only in the Ukrainian
backend bundle `resources/documents/messages_uk.properties`; only the server calculates money (the web shows server
strings); `invoice` and `certificate` are append-only (certificate: annul columns once); no personal data in logs;
new dependencies only PDFBox 3.0.8 and ZXing core 3.5.4 (javase 3.5.4 test scope), pinned exactly; no edits to
generated code; Conventional Commits, no AI attribution in commits. Builders run only the slice's Verify command and
the tests of the classes they changed — never the full backend suite (`./mvnw verify`, `make test`, `make check`);
the full suite runs once in Phase 4. Every Verify task stops anything it started and deletes its own temporary files.
References "TC x.y" are sections of `technical-considerations.md`; "FS x.y" of `functional-spec.md`. The official NBU
text is extracted at `/private/tmp/claude-501/-Users-alex-IdeaProjects-nadel-platform/2b5d7728-8708-45b9-b4c7-7c43fe039804/scratchpad/nbu/nbu97.txt`
