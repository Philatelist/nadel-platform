# Tasks — 001 Members and Access Control

Common rules for every task: follow `CLAUDE.md` (English only outside `packages/shared/src/i18n/uk.ts`, contract first,
new Flyway migrations only, RLS + `tenant_isolation` + `tenant_id` index + isolation test per tenant table, `PERM_*`
checks only, no personal data in logs, exact dependency versions, named exports, Prettier). Change
`api/openapi.yaml` first and run `make gen`; commit the regenerated `packages/api-client/src/generated`. Backend
single-test command: `cd backend && ./mvnw -B test -Dtest='<Classes>'` (requires JDK 25 and Docker). Never use
`./mvnw verify -Dtest=…` (coverage floor).
