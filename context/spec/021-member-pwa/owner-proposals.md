- Added by the push slice: the three `NADEL_WEBPUSH_*` lines with comments (not part of slice 1).
- Slice 2 (stand): the exact lines, after the other backend secrets:

  ```
  # Web Push (VAPID). The key pair is generated by ./stand-init.sh when empty and kept on later runs; leave both empty.
  # Rotating it drops every phone's subscription. The subject is a mailto: or https: contact for push services.
  NADEL_WEBPUSH_PUBLIC_KEY=
  NADEL_WEBPUSH_PRIVATE_KEY=
  NADEL_WEBPUSH_SUBJECT=mailto:admin@nadel.example.com
  ```

  `stand-init.sh` sources `.env` with `set -a`, so the empty lines are what it looks for; compose defaults
  `NADEL_WEBPUSH_SUBJECT` to `mailto:admin@$NADEL_DOMAIN` when the line is absent.
