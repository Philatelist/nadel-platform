# Tasks: 011 Ledger, charges and period closing

Spec: [functional-spec.md](functional-spec.md) · Tech: [technical-considerations.md](technical-considerations.md)

Rules for every task: follow `CLAUDE.md` (English in code, comments and docs; demo data in Ukrainian; the UI shows one
language at a time — every system text from `packages/shared/src/i18n` uk + en, user content marked with
`data-user-content`, the local ESLint rule must pass; contract first with `make gen`; existing migrations never edited,
one new migration per slice from `V13`; RLS + `tenant_isolation` + tenant index + isolation test for every new table;
permissions not role names; money is `Money`/`BigDecimal`, rates `Rate`, quantities `Quantity`/`MeterValue`, never
`double`/`number`; rounding only in `Money`; only the server calculates; the ledger is append-only; cross-module side
effects through events (ADR 0007 listener pattern); audit values are codes and parameters; no personal data or reasons
in logs; no edits to generated code; pin exact dependency versions; no mobile changes). Do not commit; report every
file created or changed.
