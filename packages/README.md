# Shared packages

TypeScript packages used by `web` and `mobile`. Rules: root [CLAUDE.md](../CLAUDE.md).

| Package | What it is | Notes |
|---|---|---|
| `api-client` (`@nadel/api-client`) | Typed API client and TanStack Query hooks | Generated by orval from `api/openapi.yaml` with `make gen`. Never edit `src/generated/`; only `src/http.ts` is hand-written |
| `shared` (`@nadel/shared`) | Money and area formatting, i18n catalogs (`uk` default, `en`) | Clients display money, never compute it |
| `ui-tokens` (`@nadel/ui-tokens`) | Colors, spacing, radius, fonts for web and mobile | Plot status colors are semantic, never the UI accent |

## Check

pnpm -r typecheck
